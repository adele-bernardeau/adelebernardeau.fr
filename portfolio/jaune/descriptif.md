# Analyse architecturale : la médiathèque François-Mitterrand, Poitiers

_Projet individuel._

Étude du bâtiment conçu par Laurent Beaudouin et Sylvain Giacomazzi (1996). Le but de ce projet était de réaliser une affiche qui comporte toutes les informations nécessaires : contexte, composition, matériaux, espaces. Elle est complétée par une maquette à l'échelle 1/1000.
